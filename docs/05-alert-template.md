# 알림 템플릿 신청 (콘솔)

물품이 0이 된 채로 시간이 지나면 다른 구성원에게 보내는 알림입니다. 템플릿은 **1개**만 신청하고,
첫 알림과 다시 알림이 같은 문구를 씁니다. 화면은 `miniapp/design/wireframes.html`의 E 섹션(12-a ~ 12-d)입니다.

## 신청 항목

| 항목 | 값 |
|---|---|
| 캠페인 유형 | 기능성 메시지(스마트 발송) |
| 제목 (7자 이내, 명사형, 마침표 없음) | `재고 소진` (5자) |
| 본문 (25자 이내, 변수는 2글자, 마침표) | `{itemName} 재고가 없어요.` (11자) |
| 변수 | `itemName`(물품 이름), 서버가 8자를 넘으면 `…`으로 줄여 보냄 |
| 랜딩 | `intoss://salim-link/items` |
| 알림 동의문 | 콘솔이 요구할 때만 연결(요구하면 12-d 화면 추가) |

예) `치약 재고가 없어요.`

## 카피 리뷰 기준(확인한 내용)

- 해요체, 본문은 문장형 `~요.` 으로 끝에 마침표, 제목에는 마침표 없음
- 판촉·구매 권유 표현 금지 (`사러 가볼까요?`, `이런 상품은 어떠세요?` 등) → 상태만 알린다
- 승인 전에는 테스트 발송도 불가, 검수에 영업일 기준 약 2~3일

## 서버 설정

| 환경변수 | 의미 | 기본 |
|---|---|---|
| `ALERT_TEMPLATE_SET_CODE` | 승인된 템플릿 코드. 비어 있으면 발송하지 않고 로그만 남김 | (비어 있음) |
| `family-share.alert.out-of-stock-delay` | 0이 된 뒤 첫 알림까지 | `PT3H` |
| `family-share.alert.reminder-interval` | 다시 알림 간격 | `P1D` |
| `family-share.alert.max-reminders` | 총 알림 횟수(첫 알림 포함) | `3` |

## 동작 규칙

1. 수량이 0이 되면 알림 대기를 시작한다 (`ItemOutOfStockEntered`).
2. 대기 시간이 지나면, **0으로 만든 사람을 뺀** 활성 구성원에게 보낸다. 발송 키는 `x-anon-key`.
3. 이후 간격마다 같은 알림을 `max-reminders` 번까지 보낸다.
4. 수량이 다시 0을 넘으면(`ItemRestocked`) 남은 알림은 취소된다. 공간을 해산해도 같이 지워진다.
5. 한 명에게 보내다 실패해도 다른 사람 발송은 계속한다(실패는 경고 로그).
