살림잇다 · 화면 와이어프레임 v0.2

토스 앱 안에서 실행되는 미니앱 화면입니다. React + TDS(@toss/tds-mobile) 컴포넌트 기준이고, 각 화면 아래에 쓰는 컴포넌트와 호출하는 서버 API를 적었습니다.
실제 앱에서는 위쪽 내비게이션 바(앱 이름, ⋯, ✕)를 토스가 그려 주므로 우리가 만들지 않습니다. 라이트 모드 기준이며 다크 모드는 TDS 색 토큰이 자동 대응합니다.

주요 행동(파란색 하나만 강조) 부족·위험 연한 강조 GET /me 호출하는 API API 추가 필요 지금 서버에 없는 것
진입 앱 열기 → 자동 식별키 교환(POST /auth/toss/exchange) → GET /me
  ├ 공간 없음 → 1 시작 → 2 공간 만들기 → 3 홈
  ├ 공간 있음 → 3 홈 ↔ 4 물품 상세 ↔ 5 물품 추가·수정
  └ 초대 링크로 진입(intoss://salim-link/invite?token=…) → 9 초대 수락 또는 10 초대 불가
알림 물품이 0이 된 채 3시간이 지나면 다른 멤버에게 푸시 → 탭하면 12-b 물품 상세 → 사러 가기
